# My Guitar Path

Mi cuaderno de estudio de guitarra: canciones que estoy aprendiendo, con tablatura propia (`<guitar-tab>`, SVG + WebAudio), tempo, dificultad, análisis punteo/rasgueo y enlaces a YouTube. Sin dependencias ni build: abre `index.html`.

## Aviso
Las canciones pertenecen a sus autores. Las tablaturas son fragmentos/transcripciones para estudio personal y educativo. El código es de dominio público ([Unlicense](LICENSE)).
